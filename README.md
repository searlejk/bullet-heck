# Bullet Heck

A top-down bullet-hell roguelike you play in the browser. Dive through endless dungeon levels, find and fuse guns, and spend embers at the Lantern Camp on upgrades that last between runs.

**Play:** https://searlejk.github.io/bullet-heck/

## Controls

| Action | Keys |
|---|---|
| Move | W A S D |
| Aim and shoot | Mouse, hold the left button |
| Auto-fire | X |
| Roll | Space or right-click |
| Bomb | F |
| Use, open, pick up | E |
| Swap guns | Q, the mouse wheel, or 1 / 2 |
| Pause, guns, Almanac, Fusion tree | Esc |

Phones get twin-stick touch controls.

## Saving

Your progress saves automatically in your browser (localStorage, with a backup copy). A run in progress is saved too, so a reload carries on where you were. To move your progress to another browser or device, use **Esc > Settings > Save to file**, then **Load from file** on the other one. Clearing this site's data in your browser erases the save.
